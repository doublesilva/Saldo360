# T10.3.4.1 — Auditoria e correção de vulnerabilidades NuGet

## Diagnóstico

A restauração após a T10.3.4 identificou `System.Security.Cryptography.Pkcs` e `System.Security.Cryptography.Xml` na versão `10.0.12`. A origem não era o `UglyToad.PdfPig`: a cadeia vinha de `Microsoft.AspNetCore.DataProtection` usada pelo `Microsoft.AspNetCore.DataProtection.EntityFrameworkCore`, referência direta do projeto de infraestrutura. Os mesmos pacotes também eram resolvidos pelo grafo ASP.NET/EF dos testes.

Os avisos oficiais consultados foram:

- [GHSA-2fmv-rv2c-59x7 / CVE-2026-70162](https://github.com/advisories/GHSA-2fmv-rv2c-59x7): negação de serviço por custo quadrático em `EnvelopedCms.Decode`.
- [GHSA-846f-f764-76mx / CVE-2026-84008](https://github.com/advisories/GHSA-846f-f764-76mx): negação de serviço em `SignedCms.CheckSignature`.
- [GHSA-7hqp-7c5m-4vq6 / CVE-2026-96960](https://github.com/advisories/GHSA-7hqp-7c5m-4vq6): vulnerabilidade no pacote XML que depende do PKCS.

Os avisos indicavam como afetadas as versões até `10.0.12` e como corrigida a versão `10.0.13`.

## Correção aplicada

Foram atualizadas, de forma coordenada, as referências Microsoft .NET 10 de `10.0.12` para `10.0.13`:

- `Microsoft.AspNetCore.DataProtection.EntityFrameworkCore`;
- `Microsoft.Extensions.Diagnostics.HealthChecks.EntityFrameworkCore`;
- `Microsoft.AspNetCore.Authentication.OpenIdConnect`;
- `Microsoft.EntityFrameworkCore.Design`;
- `Microsoft.Extensions.DependencyInjection.Abstractions`;
- `Microsoft.AspNetCore.Mvc.Testing`;
- `Microsoft.EntityFrameworkCore.InMemory`;
- ferramenta `dotnet-ef`.

O `UglyToad.PdfPig` permaneceu em `1.7.0-custom-5`; a extração textual continuou funcionando sem alteração de API. Nenhum `NuGetAudit`, `NoWarn` ou supressão de vulnerabilidade foi adicionado.

## Validação

Executado com a variável `NuGetAudit` ausente do processo:

```text
dotnet restore Saldo360.slnx              OK
dotnet list ... package --vulnerable      nenhum pacote vulnerável
dotnet tool restore                        OK (dotnet-ef 10.0.13)
npm run check                              OK
git diff --check                           OK
```

Resultado do check: 552 testes backend aprovados, 220 testes frontend aprovados, build aprovado e lint concluído. Permanecem apenas três avisos preexistentes de `react(set-state-in-effect)` no frontend.

Os testes específicos da pré-visualização PDF continuam aprovados, incluindo valores brasileiros, datas, páginas, parcelas, pagamentos, créditos, estornos e encargos.

## Riscos remanescentes

Não foram encontrados pacotes vulneráveis pela auditoria NuGet atual. A atualização depende do SDK/runtime .NET 10.0.13 no ambiente de execução; ambientes que fixem runtime anterior devem ser atualizados antes de qualquer implantação. Nenhuma alteração de produção foi realizada.
